Ben Ege. Ankara Medipol Üniversitesi’nde arka uç yazılım geliştirme öğrencisiyim.

Python ile backend geliştirme, API entegrasyonları ve otomasyon üzerine çalışıyorum. Siber güvenlik ve Linux da öğrenme yolculuğumun bir parçası. Git ve GitHub ile çalışmalarımı düzenli tutuyor; öğrendiklerimi küçük, somut projelerde deniyorum.
